# Third-party notices

No third-party runtime code is currently bundled in the distributable WordPress
plugin.

Development dependencies are installed through npm and are not intended to be
included in release ZIP files. Their licenses are provided with the respective
packages in `node_modules`.

The plugin integrates with the external YouTube service. YouTube is not part of
this project and is subject to Google's terms and privacy policy. The external
service and all contacted domains will be documented before the first release.

This file must be updated whenever a third-party runtime component is added,
removed, or updated.
