## Local evidence

Codex executed the 45 CI contract tests: all passed. They cover path allowlists,
mixed changes, unknown paths, rename/deletion handling, full overrides, missing
comparison data, required-job failures/cancellations/skips, Markdown reference
links and fenced examples, version mismatches, invalid release tags, checksum
corruption, forbidden package entries and missing runtime files. The independent
review led to checks for raw HTML destinations and required PHP/JS/CSS assets.
Translation changes retain full CI so WordPress-based catalog reproducibility
cannot be skipped.

`npm run test:local` passed: 36 PHP tests (141 assertions), 87 JavaScript tests,
38 Playwright tests, PHP/JS/CSS lint, formatting, translation reproducibility,
production build and Plugin Check. Plugin Check reported the existing short
description truncation warning. `npm run check:docs` passed for 53 Markdown
files and 58 stable IDs. `npm run check:package` verified the production ZIP's
22 files and SHA-256. The focused checks passed again after review corrections.

Scripts 36's `wp-scripts format --check` was observed rewriting files and
returning success. `format:check` now calls Prettier's actual `--check` mode,
excludes generated `build/` and `dist/`, and reports deviations without writing.
One existing browser fixture received an indentation-only formatter correction.

The initial local dependency tree contained Scripts 35 while the lock requires
Scripts 36. Installing the newly explicit Markdown dependencies refreshed it.
The host Node.js is one patch below the declared minimum; GitHub Actions uses
the declared version. Further checks and remote acceptance are recorded below
as they complete.
