# Release acceptance for version 0.1.0

Acceptance date: 12 September 2026.

This record preserves the evidence and open items for the 0.1.0 Alpha release.
Current release procedures are defined in [release packaging and
publication](../../operations/releases.md). Current test procedures are defined
under [testing](../../testing/strategy.md).

## Outcome

Version 0.1.0 was approved and tagged as an Alpha release. The generated ZIP
passed the recorded automated, packaging and manual installation checks. Manual
keyboard and screen-reader acceptance and the site-specific privacy review
remained open. These limitations were retained explicitly, and the release was
classified as an Alpha version that would continue to be developed.

## Recorded evidence

- The automated production build, runtime allowlist, reproducibility and
  checksum checks passed.
- The generated ZIP was installed through the WordPress administration upload
  flow. The plugin was activated and used as a Gutenberg block with a real
  playlist; the manual use check passed.
- The project owner had accepted the editor and privacy flow, availability
  classification and timeout, navigation and independent instances, the layout
  and title refinement, and German/English switching.
- Tag `v0.1.0` identifies the accepted repository state. The corresponding
  [GitHub Release](https://github.com/quasipapa/youtube-player/releases/tag/v0.1.0)
  publishes the installable ZIP and checksum.

## Open acceptance

- Manual keyboard and screen-reader acceptance was not yet explicitly
  confirmed.
- The privacy text and consent-manager setup still required assessment for each
  intended production site.

These items concern human perception and site-specific integration. Automated
checks cannot close them, and a future release must reassess them under the
current [manual acceptance procedure](../../testing/manual-acceptance.md).
