# Adjust player appearance

Select the block and open **Player size** in the block settings sidebar.

| Setting | Effect |
| --- | --- |
| Maximum width (px) | Limits block width; leave empty to use the available content width |
| Maximum height (px) | Limits the video area; the title and controls remain outside that area |
| Aspect ratio | Choose 16:9, 4:3, 1:1 or Custom |
| Custom aspect ratio | Enter width:height, for example 9:16 for a portrait player |

Use positive whole pixels for size limits. Follow the editor's validation
messages if the dimensions or ratio are unsuitable. The player remains
responsive within the available content area.

## Alignment

Use the block toolbar's alignment control. Available choices depend on the
theme. Wide and full alignment need theme support. Center centers the block;
left and right allow following text to wrap when sufficient space remains.
Choose a maximum width that leaves room for that text. On narrow screens,
side alignment returns to the available content width.

Save and preview the page to assess the result in your theme. Check narrow
screens and long titles as well as the editor preview.

Colors, spacing and focus presentation are controlled by the theme. Ask your
theme developer to use the [theme integration](../integrations/theming.md)
when changes beyond the block's settings are needed.
